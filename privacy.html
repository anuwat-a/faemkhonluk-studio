This policy explains how the Faem Khon Luk Studio uploader tool ("the tool") handles data. The tool is a private command-line program. Only the channel owner uses it, to upload the owner's own videos to the owner's own YouTube channels.

YouTube API Services

The tool uses YouTube API Services (YouTube Data API v3). By using the tool you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data the tool accesses

  • OAuth scopes: youtube.upload (to upload videos) and youtube.readonly (to confirm which of the owner's channels a sign-in belongs to).
  • API calls: videos.insert to upload and schedule the owner's videos, and channels.list with mine=true to read the owner's own channel name and ID.
  • The tool does not read, collect or analyse any other channel's data, any viewer's data, comments, or analytics.

What data the tool stores

  • An OAuth refresh token for each of the owner's channels, stored only on the owner's own computer.
  • A local log of upload results (video ID, URL and scheduled publish time) so the same video is never uploaded twice.

Nothing is stored on a server. No data is sold, shared with or disclosed to third parties, and no data is used for advertising.

How to revoke access and delete data

  • Access can be revoked at any time from the Google security settings page: security.google.com/settings/security/permissions.
  • Deleting the local token file removes the tool's access immediately. Stored tokens and upload logs are deleted within 7 days after access is revoked, or on request.
  • The only API data kept is the ID of each video the owner uploaded with the tool, which is needed to avoid duplicate uploads. Channel names read with channels.list are only shown on screen and are not stored.

Cookies

The tool runs on a computer, not in a browser, and does not use cookies. This website does not use cookies or tracking.

Changes

If this policy changes, the new version will be posted on this page with a new date.
